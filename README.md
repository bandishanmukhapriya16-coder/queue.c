
# Queue Implementation in C

## Project Overview
This project demonstrates the implementation of the Queue data structure using the C programming language. A Queue follows the First In, First Out (FIFO) principle, where the first element inserted is the first element removed.

## Features
- Enqueue operation
- Dequeue operation
- Display Queue Elements
- View Front Element
- Check Queue Overflow
- Check Queue Underflow

## Technologies Used
- C Programming
- Data Structures and Algorithms (DSA)

## Concepts Covered
- Arrays
- Functions
- Queue Data Structure
- FIFO Principle
- Memory Management
